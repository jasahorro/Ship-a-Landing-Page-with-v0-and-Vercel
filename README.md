## Introducing Today's Project!

In this project, I'm going to build a production-ready e-commerce landing page using AI with v0.dev, export the code to GitHub, and deploy it live to the web using Vercel to gain automatic HTTPS, a global CDN, and edge protection.

### Key tools and concepts

The key tools I used include v0.dev for AI-powered UI generation, GitHub for version control and repository management, and Vercel for automated cloud deployment. Key concepts I learnt include rapid component prototyping using natural language prompts, Git branch workflows and pull requests, and setting up continuous deployment with built-in HTTPS and security.

### Challenges and wins

This project took me approximately 25 minutes. The most challenging part was understanding the flow of exporting from v0 to GitHub and setting up automated continuous deployment with Vercel. It was most rewarding to see my e-commerce landing page instantly go live with a secure custom URL and a professional dark mode design after merging my pull request!

### Project Reflection

I did this project today to learn how to build and deploy a production-ready e-commerce landing page using AI with v0.dev, export code to GitHub, and set up continuous deployment with Vercel. Another skill I want to learn is how to integrate advanced backend payment processing APIs like Stripe.

## Publishing a Live Site with Vercel

In this step, I'm going to export my v0 project to GitHub so that I can set up continuous deployment with Vercel.

### Exporting to GitHub

I exported my v0 project to GitHub by clicking the GitHub icon in v0, selecting connect, and creating a repository. Now my code is stored in my GitHub repository.

![Image](https://nextwork.ai/overjoyed_magenta_proud_yak/uploads/065fd851-4e5d-5bd2-828b-d653483d86a9_j1k3y6z9)

### Vercel's built-in security

Vercel handles HTTPS (encrypted connections) automatically, including automatic SSL certificate provisioning and renewals. The padlock icon in your browser's address bar means your connection to the site is secure and encrypted.
